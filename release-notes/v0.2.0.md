# Release Notes – v0.2.0

This release focuses on improving editor consistency, expanding formatting capabilities, and introducing productivity shortcuts. Significant progress has been made in aligning editor and preview behavior, though this has introduced a new area of work around PDF export consistency.

---

## ✨ New Features

### Image alignment controls
Images can now be aligned directly within the editor:
- Left alignment  
- Center alignment  
- Right alignment  

### Keyboard shortcuts
Added support for core editing and file actions:
- Bold formatting  
- Emphasis/italic formatting  
- Save file  
- New file creation  
- Export to PDF  

These additions significantly improve editing speed and workflow efficiency.

---

## 🔧 Improvements & Fixes

### Major editor–preview consistency overhaul
A key focus of this release was resolving mismatches between the editor and preview rendering.  
The visual and structural alignment between both views has been significantly improved.

### Image handling improvements
Images are now fully supported within the editor, including alignment options, improving parity between editing and preview experiences.

### Font and layout stability improvements
Several underlying layout and rendering inconsistencies have been reduced, improving overall editor stability in typical usage scenarios.

---

## ⚠️ Known Issues

While major inconsistencies between the editor and preview have been addressed, this change has introduced a new issue:

### Preview vs. PDF export mismatch
After aligning the editor and preview systems, a new discrepancy has appeared between the preview output and exported PDF.  
This is now the next priority fix.

### Other known issues
- PDF export filename does not yet use the user-defined export name (defaults to in-app document name)
- Export font styling is unstable, with font size not consistently applied
- Copy-pasting code blocks may introduce an additional unwanted wrapper/header
- Missing or incomplete formatting features:
  - Links  
  - Mathematical expressions  
  - Strikethrough  
  - Checkbox lists  
- Editor window sizing may be inconsistent when not maximized
- Inline formatting is still inconsistently serialized to Markdown instead of structured rich text

---

## 🧭 What's Next

The next focus is stabilizing the export pipeline, specifically resolving inconsistencies between **preview rendering and PDF output**, followed by continued work on formatting completeness and export reliability.
