# v0.2.3

## New

* **Strikethrough.** `~~text~~` is now a fully supported mark — type or\
  paste it, select text and click the new Strikethrough button (Home >\
  Format), and it round-trips correctly through markdown.
* **Math (KaTeX).** Inline math (`$E=mc^2$`) and math blocks (`$$ ... $$`)\
  are now parsed, rendered with KaTeX, and serialized back to markdown.
  * New "Inline Math" (Σ) and "Math Block" buttons in Home > Format /\
    Insert.
  * Click a rendered formula to edit its raw LaTeX source.
  * In a math block, press Enter to exit back to the document (landing on\
    a new line below), or Shift+Enter to add another line of LaTeX. In\
    inline math, Enter exits (no multi-line content).
  * Press Escape at any time to exit editing and commit the formula.
  * Currency-style text like `$5 + $10` is correctly left as plain text.
  * The LaTeX source editor has no border/box — it looks like plain text.\
    The cursor no longer gets stuck inside it: arrow keys at the start/end\
    of the source (or top/bottom line, for blocks) exit back into the\
    surrounding document, and entering edit mode no longer selects the\
    whole formula.
* **Markdown help panel.** A new "Markdown Guide" panel in the activity bar\
  (replacing the old empty Help tab) gives a quick reference for every\
  supported markdown construct — headings, bold/italic/strikethrough,\
  inline code & code blocks, links, images (including the\
  `=WIDTHxHEIGHT:align` resize/alignment syntax), blockquotes, lists\
  (bullet, numbered, task), tables, horizontal rules, and math — each with\
  a short description and the syntax to type.
* **Task lists (checkboxes).** `- [ ] todo` / `- [x] done` are now parsed,\
  rendered as clickable checkboxes, and serialized back to markdown.
  * New "Task List" button (Home > Insert) turns the current line into a\
    task item, or cycles an existing list item through\
    unchecked -> checked -> plain bullet.
  * Type `[ ] ` or `[x] ` at the start of a list item to convert it to a\
    task item.
  * Click a checkbox to toggle it.
  * Pressing Enter inside a task item continues the task list with a new\
    unchecked item.

## Fixes

* **Pasting markdown now actually renders.** Pasted text is parsed with the\
  full markdown parser, so headings, lists, bold/italic, blockquotes, code\
  blocks, etc. become real elements immediately instead of sitting as inert\
  text until you start typing.
  * Works for plain-text copies and for clipboards that only carry HTML\
    (e.g. "Copy code" buttons) — HTML is converted back to markdown source\
    (`<br>`/block elements -> newlines) before parsing.
  * Fixed a parser crash on `~~strikethrough~~` (added proper strikethrough\
    support to the schema, parser, and serializer) that was silently\
    breaking *all* pasted content whenever it appeared anywhere in the\
    clipboard.
* **Copying from the editor now copies markdown.** Selected text is\
  serialized back to markdown syntax (`**bold**`, `# Heading`, `- item`,\
  etc.) instead of plain stripped text.
* **Heading and paragraph spacing restored.** Headings and paragraphs were\
  rendering with zero vertical margin (a stale/unused CSS class meant no\
  spacing rules actually applied), making multi-block content look\
  squashed together. Real spacing is now applied.
* **Document no longer resizes/lags on tab switch.** Switching tabs now\
  triggers the same resize recalculation as a normal edit, instead of\
  waiting for the next click in the editor.
* **Page-count calculation fixed.** The "add another page" threshold now\
  matches how the document is actually laid out (one continuous flow with\
  a top and bottom margin), so a new page appears at the right time instead\
  of too late.
* **Editor page width matches preview/PDF.** The editor page no longer\
  shrinks narrower than the preview/PDF page on smaller windows.
