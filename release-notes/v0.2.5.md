# v0.2.5

## New

* **Quick Note window.** Press `Alt+N` from anywhere on your desktop\
  (even while Saguinus is in the background) to open a small floating\
  notepad. The window hides rather than closes, so subsequent presses\
  are instant. It auto-saves continuously to a dedicated notepad file\
  and supports the essentials: bold, italic, strikethrough, inline\
  code, bullet lists, and task lists, plus heading shortcuts (`# `,\
  `## `, etc.), blockquote shortcuts (`> `), and inline markdown\
  decoration (markers are hidden while you're not near them). A Pin\
  button keeps it always-on-top; an "Open in Editor" button promotes\
  the note into a full editor tab if you want to keep going there.\
  The window's position and size are remembered across restarts.
* **Timestamp shortcuts in Quick Note.** Type `--now` for a full\
  date-and-time stamp, `--date` for just the date, or `--time` for\
  just the time — each is replaced the moment you type the last letter.
* **Paste and drop images into Quick Note.** Dragging or pasting a\
  real image file links it by path; pasting raw clipboard image data\
  (e.g. a screenshot) writes it to an assets folder inside the notebook\
  directory and inserts it with a relative path, so the note stays\
  self-contained.
* **Notebook panel.** The activity bar now has a NOTEBOOK section that\
  lists every heading in your notepad as a clickable navigation entry.\
  An Assets section below it shows any files saved to the notebook's\
  assets folder; the section is hidden when no assets exist.
* **Page breaks.** Insert a hard page break with `Ctrl+Enter`, by\
  typing `+++` at the start of a line, or from the Insert menu.\
  Page breaks are saved as an invisible `<!-- pagebreak -->` HTML\
  comment, so the file stays clean in other editors. In the editor\
  they appear as a dashed rule; in paged preview and PDF export they\
  force a real page break.
* **Table of contents styles.** The document-level TOC block now\
  supports three visual styles — Classic (dotted leaders and page\
  numbers), Simple (clean with page numbers), and Minimal (plain list)\
  — selectable from a Configure button next to the TOC toolbar control.\
  Page numbers are real: they reflect the actual paginated layout.\
  The heading levels included (H1–H6) are configurable per document.\
  TOC links are now clickable in the preview pane. PDF exports include\
  a full nested bookmark outline (visible in any PDF reader's sidebar)\
  built from the same heading tree.
* **Paragraph alignment.** Paragraphs (and headings) can be set to\
  left, center, or right alignment from the toolbar. The choice is\
  stored as an HTML comment at the end of the paragraph in the saved\
  markdown, so the content is always readable in any other editor —\
  only the alignment won't carry over. Center and right are\
  Saguinus-specific; this is noted in the known-issues list.
* **Image alignment and multi-image rows.** Images can be aligned\
  left, center, or right. Aligned images sit on their own line;\
  unaligned images are inline and can sit beside text or next to\
  each other. Paragraphs containing two or more adjacent images\
  are automatically arranged in a three-column row, with each image\
  placed in the column matching its alignment. Images are now also\
  capped at the editor's content width so they never overflow the page.
* **Close Folder.** A × button in the FOLDER panel header closes the\
  current workspace folder without closing any open files.
* **Tab external indicator.** Tabs whose file lives outside the current\
  workspace folder now show a small amber dot, making it obvious which\
  files are orphaned from the project.
* **Headless mode.** When the window is narrowed below a threshold\
  the sidebar and some toolbar sections automatically collapse to give\
  more room to the editor. The topbar can also be collapsed manually\
  with a toggle button; both states persist across restarts.
* **Insert menu.** Toolbar menu tabs now include an Insert tab for\
  inserting footnotes, page breaks, tables, images, and more, grouped\
  in one place.
* **macOS support.** A `.dmg` for macOS is now built alongside the\
  Windows installer and Linux packages. This is the first macOS\
  release; it is unsigned, so Gatekeeper will show an "unidentified\
  developer" warning on first launch (right-click the app → Open to\
  bypass it). Code signing and notarization will follow once an Apple\
  Developer account is in place.

## Fixes

* **AI-generated `__bold__` and `_italic_` now render correctly.**\
  The inline-decoration scanner only recognized `**` and `*` markers,\
  so text generated by AI tools using the double-underscore variant\
  appeared as literal underscores. Both variants are now normalized at\
  load time.
* **Page sizing was wrong at launch and after session restore.**\
  Content could overflow past the last page guide if the page-height\
  calculation fired before the layout had fully settled. A\
  `ResizeObserver` now watches the editor container and recalculates\
  whenever it actually reflows, so the guides are correct from the\
  moment the document is ready.
* **Recent Files and Backups dropdowns were clipped inside the toolbar.**\
  The toolbar container had `overflow: hidden`, which clipped any\
  absolutely-positioned dropdown that extended below it. Changed to\
  `overflow: visible`.
* **Auto-capitalization now works after sentence-ending punctuation.**\
  The first letter after `. `, `! `, or `? ` is now capitalized\
  automatically, extending the existing paragraph-start cap to cover\
  mid-paragraph sentences. A position bug in the earlier implementation\
  that silently ate the space before the capitalized letter has been\
  fixed; the space is always preserved.
* **Auto-capitalization now applies to headings.** Previously only\
  triggered for paragraphs.
* **Spellcheck context menu now works in the Quick Note window.**\
  Right-clicking a misspelled word in Quick Note now offers the same\
  suggestions, "Add to Dictionary", and standard edit actions that the\
  main editor already had.
* **Select dropdowns (font family, font size) now match the rest of\
  the UI.** The native OS chrome was removed and the controls were\
  restyled to match Saguinus's own dropdown and popup appearance.
* **Popup and dropdown shadow/radius values unified.** Minor visual\
  inconsistencies between the link popup, footnote hover popup, and\
  the note image popup have been corrected.

## Verified (no change needed)

* Quick Note window state (bounds, pin, theme) persists correctly\
  across restarts and correctly inherits theme changes made in the\
  main editor.
* "Open in Editor" from Quick Note opens the notepad as a real tab\
  in the main editor with the correct path and content.
* Page breaks export correctly in both paged preview and PDF — forced\
  page break is applied, no orphaned heading or line appears at the\
  bottom of a page.
* TOC page numbers in Classic and Simple styles match the actual\
  paginated layout, including documents with page breaks.
